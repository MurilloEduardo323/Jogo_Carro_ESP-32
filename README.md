# Endless Road — ESP32 + MPU-6050

Protótipo inspirado na imagem enviada: estrada em perspectiva, montanhas low-poly, barreiras vermelhas/brancas, carro vermelho, obstáculos, pontuação e velocidade crescente.

Controles: setas/A-D para teste. O botão Conectar ESP32 lê `STEER:-100` até `STEER:100` a 115200 baud via Web Serial.

Abra a pasta no VS Code e use Live Server ou outro servidor local. Web Serial funciona em `localhost`.
